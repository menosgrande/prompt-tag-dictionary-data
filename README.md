# prompt-tag-dictionary-data

## 作業対象の原則

今後、このプロジェクトの調査・整理・分類・翻訳修正・データ編集・検証・更新は、本リポジトリ `menosgrande/prompt-tag-dictionary-data` を作業対象とする。

**無印版 `menosgrande/prompt-tag-dictionary` は使用しない。**

- 無印版を作業起点にしない。
- 無印版からデータやファイルを取得しない。
- 無印版に対する編集・修正・更新を行わない。
- 調査や照合の参照元としても使用しない。

今後の作業は、データ版の内容を正本として進める。無印版の情報が必要に見える場合も、独断で参照せず、先にユーザーへ確認する。
